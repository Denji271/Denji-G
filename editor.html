Map Maker

  • Pick a tile and draw with the left mouse button; the right button erases.
  • S marks where players start (up to four), G is the exit or finish line, the flag is a checkpoint.
  • A coloured switch holds the door of the same colour open while somebody stands on it. The key (co-op) has to be carried to the exit.
  • A normal jump climbs 3 blocks; standing on a friend's head you reach 4. A spring throws you about 8 blocks high.
  • Test lets you run around in your map (Esc stops). Save keeps it in this browser — then host a Co-op, Race or Brawl room and pick it under Level. Your friends receive the map automatically.
  • Share code copies the map as text, which a friend can paste with Import code.
  • 🎲 Random map builds a whole new level for the chosen game — play it as it is or use it as a starting point.
  • 🤖 Robot check sends a little robot through your map with the real game physics and tells you whether it can be finished (and, for co-op, whether it really needs teamwork).
